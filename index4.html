Famílias de Microcontroladores

ATmega (AVR)

Excelente para projetos de alto desempenho e baixo consumo. Base da plataforma Arduino.

  • 32KB Flash
  • ADC 10-bit
  • Fácil programação
PIC (Microchip)

Linha robusta usada em aplicações industriais e comerciais. Grande variedade de periféricos.

  • Alta confiabilidade
  • PWM avançado
  • Baixo custo
8051

Clássico da eletrônica. Ideal para aprendizado de arquitetura e projetos simples.

  • 4 portas I/O
  • Interrupções
  • Legado educacional

Arduino - A Revolução Maker

Baseado principalmente no ATmega328P, o Arduino democratizou o acesso à programação de microcontroladores. Milhares de projetos ao redor do mundo usam esta plataforma.

Fácil IDE Enorme Ecossistema Comunidade Ativa

Internet das Coisas (IoT)

Microcontroladores + conectividade WiFi/LoRa/Bluetooth transformam o mundo em uma rede inteligente. Monitore, controle e automatize de qualquer lugar.

Projetos Comparativos

Projeto com PIC16F877A

Pisca-pisca controlado por botão

RB0 → LED1 + 330Ω
RB1 → LED2 + 330Ω
RA0 → Botão + 10kΩ pull-up

+5V | GND 
void main() {
    TRISB = 0;
    while(1) {
        if(!RA0) { PORTB = 0x03; delay_ms(400); PORTB = 0; }
    }
}

Mesmo Projeto com ATmega328P

Pisca-pisca controlado por botão (Arduino)

Pino 2 → LED1
Pino 3 → LED2
Pino 4 → Botão (INPUT_PULLUP)

+5V | GND 
void loop() {
    if(digitalRead(4) == LOW) {
        digitalWrite(2, HIGH); digitalWrite(3, HIGH);
        delay(400);
        digitalWrite(2, LOW); digitalWrite(3, LOW);
    }
}
